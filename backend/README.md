# Back end

FastAPI service that stores trips and places, generates a day-by-day itinerary with Gemini,
flags public-holiday closures, and costs every item in local and home currency.

> **Status: M4.** Trips, places and itineraries are stored in Tiger Data (Postgres + TimescaleDB).
> Itineraries are generated by Gemini, checked against public holidays and (if a Google Maps key is set)
> real opening hours. Every item is costed per person in local currency and converted to the home currency.

## How money is handled

- **Gemini estimates local costs per person. Code does all conversion and totals** (`services/budget.py`,
  `Decimal` throughout, rounded half-up to the penny). Day and trip totals are sums of the rounded item
  values, so the numbers the user sees always add up.
- **Rates** (`services/fx.py`): cache (last 6h in the `fx_rates` hypertable) -> Frankfurter (ECB reference
  rates, no key, fetched against EUR for full precision) -> hardcoded fallback (ECB snapshot from
  2026-10-16 for 29 currencies), so the demo never breaks if the API is down.
- Every live rate is stored in `fx_rates`, which gives us FX history (e.g. for a rate chart).

## How opening hours are handled

1. **Holidays:** Nager.Date public holidays for every year the trip touches (cached in the `holidays` table)
   go into the prompt, along with each date's weekday and guidance on weekly and seasonal closures.
2. **Opening hours (optional, `GOOGLE_MAPS_API_KEY`):** each stop's weekly hours are looked up with the
   Google Places API (New). **Google is used only for opening hours**: the field mask is
   `places.regularOpeningHours`, we never use Google names or coordinates, and nothing from Google is stored.
   Plain code checks the whole visit (start + duration) fits inside the hours on that weekday.
3. **One fix pass:** any stop that is closed (per the hours, or marked closed by Gemini) is sent back to
   Gemini once to be moved or replaced. If it's still closed afterwards it's shown as `closed`.
4. **Closure check (deterministic):** on a public holiday, closure-prone stops (museum, shop, market,
   restaurant, cafe, bank, office, gallery) that are `ok` become `check_hours`. `closed` is never changed.

Final status: opening hours can only make a status more cautious, never less (weekly hours can't see seasonal
closures). Hours say closed -> `closed`; key set but no hours found -> `check_hours` (except open-air
`landmark`/`park` stops like streets and crossings); otherwise Gemini's status.
Google can't tell us holiday hours months ahead, hence step 4.

## Run locally

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate        # Windows (Git Bash); macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # fill in DATABASE_URL, GEMINI_API_KEY, GEMINI_MODEL (+ optional GOOGLE_MAPS_API_KEY)
python apply_schema.py        # creates tables + the fx_rates hypertable (safe to re-run)
python seed_demo.py           # creates/resets the demo trip t_demo0001
uvicorn app.main:app --reload --port 8000
```

Interactive docs: http://localhost:8000/docs

Tests: `python -m pytest -q` (API tests run against the DB in `DATABASE_URL` and clean up after themselves; they're skipped if it isn't set)

The password in `DATABASE_URL` can contain special characters like `@`; the app percent-encodes it.

## Endpoints

| Method + path | Notes |
|---|---|
| `GET /health` | `{ "status": "ok", "db": "ok" }`, or 503 with `"status": "degraded"` if the DB is unreachable |
| `POST /trips` | Body: Trip without `id`. Returns 201 + full Trip. Resolves country + currency via Nominatim |
| `GET /trips/{id}` | Returns Trip |
| `POST /trips/{id}/places` | Body `{ "places": [Place] }`. Missing `id`s are assigned. Returns `{ "places": [Place] }` |
| `POST /trips/{id}/itinerary` | Generates (or regenerates) and stores the itinerary with Gemini. **Takes ~20-30s**: show a loading state. 502 `generation_failed` if Gemini fails twice |
| `GET /trips/{id}/itinerary` | Returns the stored itinerary (fast). 404 `no_itinerary` if none generated yet |

**Demo trip ID:** `t_demo0001` (Tokyo, 30 Dec 2026 to 2 Jan 2027, 2 travellers, GBP).

All JSON is camelCase. Errors are always `{ "error": "<code>", "message": "<text>" }`.
`estimatedCost` and `costHome` are **per person**.
